## Media File Processing flow
Each file should be processed in this order. Tools can depend on eachother and can call helpers. See dependencies for each tool below.

The tools/media-manager/ coordinates and executes these tools:

1. tools/renamer/
2. tools/kirtan-splitter/
3. tools/gain-booster/
4. tools/class-discoverer/
5. tools/class-trimmer/
