## Goals
- Generate one or more topics that describe the class
- Generate a description for youtube
- Generate a short title for the filename

The transcription file should be used to maximize performance. The topic(s) (genre), and file title, should accurately describe the main topics discussed. And the description should also follow those topics again.

## Requirements
- Use the /transcriptions/<file> for the transcription created by the class-discoverer tool
- Determine the main topics discussed in the class. 
  - Determine 1 or more main topics, but no more than 5
  - Use the matching verse from vedabase.io to discover topics
  - A topic can never be more than 2 words
  - A topic can never be too general or broad
  - The topics must be aded to the media table on baserow
- Generate a summary description for Youtube
   - Always add our Youtube footer to each description
   - the complete description must be added to the media table on Baserow
- Generate a short and conscise title that describes the class best
   - The title must be added to the filename
   - The title must not be too general and should include the topics if possible
   - The title should be short and can be summarised

## Generating topics
During the class the speaker will touch upon certain topics from the scripture verse being discussed. The actual verse and the chapter usually sets the tone for the whole class. When the scripture and verse is determined (by the class-discoverer tool or from the filename) it can be matched to the vedabase.io which is our authoritative source of scriptures by A.C. Bhaktivedanta Swami Prabhupada.

For example the file 'sample-files/2012/Radhadesh Jan 2012/2012-01-22_KKS_CC-Madhya-20-154_Radhadesh_be.mp3' has the scripture type and verse set to "CC Madhya-lila 20.154". This can be found on vedabase.io: "https://vedabase.io/en/library/cc/madhya/20/154/". This verse does not have a purport so the transcription must be reviewed to determine the topics.

## Generate a description
The class should be summarised as a description that is about 2-3 paragraphs long. The description must be interesting and captivating, but it must reflect the topics that were generated previously.
