## Goals
This tool will use the transcription (generated by the "Class Discovery Tool") to determine the main topics (themes). Secondly it will generate a description for Youtube and last but not least it will generate a short and descriptive title that correctly reflects the main topics.
The main topics discussed and the matching verse from htps://vedabase.io must be used to generate the main topics, themes 

## Requirements
- Determine the main topics discussed in the class. 
  - Determine 1 or more main topics, but maximum 5
  - Use the matching verse from vedabase.io to discover topics
  - A topic can not be more than 2 words
  - A topic can not be too general or broad
  - The topics must be aded to the media table on baserow
- Generate a summary description for Youtube
   - Always add our Youtube footer to each description
   - the complete description must be added to the media table on Baserow
- Generate a short and conscise title that describes the class best
   - The title must be added to the filename
